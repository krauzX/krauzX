## about

I'm **Aryan Raja Pandey** — a software engineer and systems architect, and a 2nd-year computer science undergraduate at IIIT Kottayam. I build the software that runs *under* other software: compilers and transpilers, language engines, and developer tooling that makes everything else faster.

Three things drive most of what I make: **high-performance backends** that stay fast under load, **custom language tooling** that turns ideas into executable code, and **local-first AI** that runs on your own hardware instead of someone else's cloud. I care about software that stays fast when nobody is watching — and I believe effort ships what wishes only describe.

## how I work

- **The terminal is home.** Plain text, monospace, keyboard-first — if it can't run in a terminal, it isn't finished.
- **Local-first intelligence.** Models and tooling that run on your own hardware. Private by default, fast by design.
- **Build tools, not demos.** Demos impress once; tools compound. A small, sharp tool used every day beats a big one used never.
- **Monochrome discipline.** One palette, one typeface, no noise. Constraints breed clarity — in code and in design.
